# Network Time Utility
Network Time Utility is a simple Network Time Protocol (NTP) client application. You can use it to check NTP server and synchronize the local system time.<br/>
This application is free and portable that not requiring installation and it does not writes any thing to the host system.

### Download
Download the latest version from the [Releases](https://github.com/Javad-Taheri/NetworkTimeUtility/releases/latest) section.

### System Requirements
Windows Vista or later.
